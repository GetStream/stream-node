# Docs snippet tests: todo

Open issues found while testing the docs snippets, in two lists: [API spec / generator issues](#api-spec--generator-issues) (the OpenAPI spec is wrong, or the generator turns it into wrong node SDK code) and [Node SDK issues](#node-sdk-issues) (the hand-written node SDK code is wrong). The API itself works. Not fixed by the agents (no `src/` changes). Remove an entry once it is fixed.

## API spec / generator issues

- **moderation/02-quick-start/08-quick-start-feeds-v3-moderation** (API spec, to check): `AWSRekognitionRule.min_confidence` is required in the generated types (TS2741 without it), while the API accepts an `ai_image_config` rule without it (stored as `0`) and the docs treat it as optional ("Default is 50" on the call moderation page). The Node.js fence now passes `min_confidence: 50` explicitly; check whether the spec should mark it optional (and what the default really is).
- **moderation/02-quick-start/03-quick-start-feeds-moderation** (API spec): `DELETE /api/v2/moderation/feeds_moderation_template` (`v2DeleteTemplate`) has no request in the spec, so the generated method takes no arguments and sends no body. The API requires `name` in the DELETE body (code 4 `V2DeleteTemplate failed with error: "name is a required field"`; `?name=` doesn't work either), as in chat's `DeleteModerationTemplateRequest` (`Name` is `validate:"required"`). The docs' `v2DeleteTemplate({ name: "mod_tmpl_1" })`("Delete Template") fails TS2554, so a template can't be deleted from typed node SDK code (tests use`deleteFeedModerationTemplate`in`helpers/server.ts`). Other SDKs (Go `V2DeleteTemplateRequest{Name}`, Python) take a name.
- **moderation/04-configuration/05-evaluations** (API spec): `GET /api/v2/moderation/policy_tests/sets` (`listPolicyTestSets`) declares no query params, so the generated method takes no arguments and the docs' `listPolicyTestSets({ limit: 50 })` ("List evaluation sets") fails TS2554 (`yarn types:docs` reports it). The API reads `limit` / `offset` from the query string (chat `lib/moderation/controller/policytest.go`, `ListPolicyTestSets`, whose `OpenAPIInfo` has no Request); a raw `GET ?limit=1` returns one set. The Python and Go tabs pass `limit`.
- **moderation/05-content-moderation/01-check** (API spec): `POST /api/v2/moderation/analyze` (`client.moderation.analyze`) only accepts `multipart/form-data` with a JSON `payload` part (Blob, `application/json`; optional `image:<label>` file parts), but the spec declares a JSON body, so the generated method sends JSON and every call fails with code 4 `V2Analyze failed with error: "Content-Type must be multipart/form-data, got "application/json""`. The docs' "Calling Analyze" Node.js fence typechecks but can't work (`it.skip`). A raw multipart request with a `payload` Blob returns 201.
- **moderation (several pages)** (API spec): moderation endpoints marked `Ignore: true` in their chat `OpenAPIInfo` are missing from the spec, so the node SDK has no method for them (TS2339), while the docs' Node.js fences and the other SDK tabs call them. All answer when called raw (`client.moderation.apiClient.sendRequest(...)`). The tests are `it.skip('BLOCKED: SDK issue: ...')` with a narrow local cast typing the missing method: remove the casts once the methods exist.
  - `GET /api/v2/moderation/user_report` (`getUserModerationReport`; `05-content-moderation/02-flag-mute-ban`, `09-logs-and-analytics/01-logs-and-analytics`): returns `{ user, user_mutes, user_blocks }`, takes `user_id`, `create_user_if_not_exists`, `include_user_mutes`, `include_user_blocks`.
  - `POST /api/v2/moderation/bulk_submit_action` (`bulkSubmitAction`; `06-review-queue/02-actions`): `{ action, review_queue_item_ids | filters, user_id }` returns 201 `{ task_id }`.
  - `POST /api/v2/moderation/logs/export` (`exportModerationLogs`; `09-logs-and-analytics`): returns 201 `{ task_id }`.
  - `POST /api/v2/moderation/analytics` (`getModerationAnalytics`, beta; `09-logs-and-analytics`): needs `start_date` / `end_date`.
  - `POST /api/v2/moderation/usage_stats` (`queryUsageStats`, beta; `09-logs-and-analytics`): returns `{ items }`.
  - `POST /api/v2/moderation/block`: also `Ignore: true`, and a no-op on the API (201, nothing blocked); the docs' "Block" Node.js fence now uses `client.blockUsers`.
